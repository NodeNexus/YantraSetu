2. The Three Sensor Modalities in Detail

🔥

Infrared Thermography

Non-contact thermal matrix monitoring identifies stator winding insulation degradation, motor cooling fan blockage, and lubrication starvation.

Resolution32 × 24 pixels (768 points)
Field of View55° standard (110° wide option)
Refresh Rate4 – 8 Hz continuous
Thermal Range-40°C to +300°C (±1°C)
Primary ModelMobileNetV3-Small PyTorch
🔊

High-kHz Vibration Dynamics

High-frequency contact accelerometer magnetically coupled to the bearing housing. Isolates micro-shocks caused by ball defects and race flaking.

Sampling Rate20,000 samples / second (20 kHz)
Snapshot Size20,480 points per rolling frame
Time FeaturesRMS Velocity, Kurtosis, Crest Factor
StandardISO 10816-3 Severity Guidelines
Primary ModelStatistical Baseline + Random Forest
🎧

Acoustic Noise Emission

Acoustic directional microphone capturing airborne ultrasonic chattering, pump cavitation, and valve leakage preceding measurable heat rise.

Audio Sampling16 kHz mono, 16-bit PCM
Window Size1.0 – 2.0 second clips
Feature Space61 MFCC & Octave Band Features
Recall Rate97.6% on held-out test sounds
Primary ModelL2-Regularized Logistic Classifier

3. The False-Alarm Suppression Protocol

Traditional industrial monitors generate frequent false positives due to ambient factory noise and summer heatwaves. YantraSetu evaluates all incoming metrics through a formal mathematical gating function:

// Layer 1: Ambient Thermal Normalization

ΔTcasing = Thotspot − Tambient_baseline

If ΔTcasing > θthermal (where θthermal = 25.0°C above floating ambient), flag thermal anomaly candidate.


// Layer 2: Temporal Persistence Filter (Sliding Window)

Canomaly = ∑ [ s(t − i) ]  for i = 0 to (W − 1), where W = 3 consecutive windows

Trigger state: If Canomaly < W → State = "UNCONFIRMED / INVESTIGATING" (No siren alarm triggered)


// Layer 3: Multi-Signal Decision Rule

If (Vibration_Anomaly == TRUE && Acoustic_Anomaly == TRUE) → WARNING: Confirmed Mechanical Wear

If (Vibration_Anomaly == TRUE && Thermal_Anomaly == TRUE) → CRITICAL: Imminent Bearing Seizure
